# 🌱 LumenIndex Employment & Livelihoods

> Companion to **LumenIndex** — Rural Development Index for Latin America
> Built for **Living Stones Foundation** | Applied Data & Digital Innovation Lab (LATAM)

An employment and livelihoods index for 17 Latin American countries: which countries are creating work, what kind of work it is, and who gets left out. It uses the same honest methodology as LumenIndex — World Bank open data, fixed weights, deterministic tiers, and no invented numbers.

---

## 📦 What This Project Delivers

| Deliverable | Description |
|---|---|
| Employment & Livelihoods Index | Composite score (0–100) with deterministic Low / Medium / High tiers, for 17 countries · 1990–2020 |
| Streamlit dashboard | Country rankings, trends, and indicator charts (planned) |
| Clean WDI dataset | Employment indicators for all 17 countries, with coverage gaps shown as gaps |

## 🧮 Score — Methodology

Each country-year is scored 0–100. Indicators are min-max normalised across the dataset (inverted where lower is better) and combined with fixed weights:

| Indicator | World Bank code | Direction | Weight |
|---|---|---|---|
| Labour force participation, total | `SL.TLF.CACT.ZS` | Higher is better | 20% |
| Unemployment rate, total | `SL.UEM.TOTL.NE.ZS` | Lower is better | 20% |
| Female labour force participation | `SL.TLF.CACT.FE.ZS` | Higher is better | 15% |
| Youth unemployment, ages 15–24 | `SL.UEM.1524.NE.ZS` | Lower is better | 15% |
| Employment in agriculture | `SL.AGR.EMPL.ZS` | Higher is better | 10% |
| Vulnerable employment | `SL.EMP.VULN.ZS` | Lower is better | 10% |
| Wage and salaried workers | `SL.EMP.WORK.ZS` | Higher is better | 10% |

Tiers are assigned by a deterministic rule on the score:

| Tier | Rule |
|---|---|
| 🟢 High | Score ≥ 60 |
| 🟡 Medium | 35 ≤ Score < 60 |
| 🔴 Low | Score < 35 |

Missing values are imputed (median) only for scoring. Charts and downloads always show observed values, so data gaps stay visible instead of being presented as real measurements. No machine-learning model is used, so no accuracy is claimed.

## 🗂️ Data

World Bank WDI indicators for **all 17 countries**: Argentina, Bolivia, Brazil, Chile, Colombia, Costa Rica, Dominican Republic, Ecuador, El Salvador, Guatemala, Honduras, Mexico, Nicaragua, Panama, Paraguay, Peru, Uruguay — 1990–2020.

- Source: World Bank World Development Indicators (WDI)
- Coverage note: vulnerable employment and youth unemployment are patchy for some countries — missing values are shown as gaps, never filled with another country's data
- Companion project: [LumenIndex](https://github.com/Applied-Data-Digital-Innovation-Lab/lumenindex-latam) — the rural development index this project extends, using the same methodology

## ▶️ Get the Data

git clone https://github.com/Applied-Data-Digital-Innovation-Lab/lumenindex-employment.git
cd lumenindex-employment
pip install -r requirements.txt
python3 scripts/fetch_employment_wdi.py

The script writes `data/employment_wdi_17_countries.csv` with columns:
`country, country_code, year, indicator, value`.
